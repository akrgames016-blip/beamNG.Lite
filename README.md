# BeamNG.Drive Lite (Python + PyOpenGL)

Мини-симулятор в духе BeamNG: машина — не «коробка с матрицей», а **soft-body**
конструкция из узлов и балок. Кузов реально мнётся, балки рвутся, подвеска ходит,
шины считают проскальзывание. Есть **гараж из нескольких машин**, **режимы игры**
(свободная езда, тайм-трайл, дрифт), **звуки**, **тени**, **дым от шин** и
**ночной режим с фарами**.

## Установка и запуск

```bash
pip install -r requirements.txt
python run.py
# или как пакет:
pip install .
beamng-lite
```

Варианты запуска:

```bash
python run.py --width 1600 --height 900     # разрешение
python run.py --seed 42                     # другой ландшафт
python run.py --vehicle pickup              # машина из гаража
python run.py --list-vehicles               # список машин гаража
python run.py --no-vsync                    # без вертикальной синхронизации
python run.py --headless 600                # прогон физики без окна (тест)
python -m beamng_lite                       # то же, как модуль
```

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `S` | газ / тормоз (на месте `S` — задний ход) |
| `A` / `D` | руль |
| `Space` | ручник |
| `R` | респавн, `F` — поставить на колёса |
| `C` / `Shift+C` | камера: погоня → орбита → капот → свободная |
| ЛКМ/ПКМ + мышь | вращать камеру, колесо мыши — зум, `V` — вернуть за машину |
| `X` | антипробуксовка вкл/выкл |
| `I/K/J/L/U/O` | полёт свободной камерой |
| `B` / `N` | показать балки / панели кузова |
| `T` | slow-mo (×0.25), `P` — пауза |
| `Q` / `E` | передача вниз/вверх, `G` — автомат/ручная |
| `Esc` | меню (пауза) |

## Меню

При запуске — главное меню:

* **Играть** — выехать на трассу в текущем режиме.
* **Гараж** — выбор машины: седан, пикап, багги, монстр-трак (с характеристиками).
* **Режим** — свободная езда / тайм-трайл / дрифт (стрелки или Enter).
* **Ландшафт (сид)** — стрелки ←/→ генерируют другую карту.
* **Время суток** — день/ночь; ночью загораются фары, небо в звёздах.
* **Инверсия руля**, **Управление**, **Выход**.

В игре `ESC` — пауза с тем же меню.

## Режимы игры

* **Свободная езда** — вся карта: холмы, трамплины, стены для крэш-тестов,
  пирамида из ящиков, слалом, бетонные блоки.
* **Тайм-трайл** — грунтовое кольцо радиусом 72 м с 12 воротами (на карте).
  Проезжай ворота по порядку — таймер считает круг. Лучшее время пишется
  в `~/.beamng_lite/records.json` (для каждой машины и сида своё).
* **Дрифт** — очки за скорость в заносе, комбо растёт, пока не выровнялся.

## Гараж: как добавить свою машину

Машины — JSON-конфиги в `beamng_lite/vehicles/`. Физика, шкура кузова и рендер
читают всё из конфига. Чтобы добавить машину, скопируйте любой пресет и меняйте:

```json
{
  "id": "mycar",
  "name": "Моя машина",
  "color": [0.2, 0.6, 0.9],
  "sections": [[-2.0, 0.7, 0.45, 0.95], ...],
  "wheel_pos": [[-0.9, -1.4], [0.9, -1.4], [-0.9, 1.4], [0.9, 1.4]],
  "wheel_r": 0.34, "wheel_w": 0.115, "wheel_mass": 26.0,
  "body_mass": 1200.0,
  "driven": "all",
  "gears": [-3.2, 0.0, 3.2, 2.05, 1.45, 1.1, 0.85],
  "final_drive": 3.5, "max_rpm": 7000.0,
  "torque": {"base": 130.0, "peak": 175.0, "peak_rpm": 4300.0, "width": 2200.0},
  "tire_mu": 1.32,
  "aero": {"cd": 0.62, "area": 2.1}
}
```

`sections` — сечения кузова вдоль оси: `[z, полуширина, низ, верх]` (нос вперёд, +Z).
Остальное — колёса, трансмиссия, мотор (гауссов пик момента), аэродинамика.
`id` обязан совпадать с именем файла. Машина сразу появляется в гараже.

## Что внутри

- `softbody.py` — узлы + балки (пружина-демпфер), пластическая деформация
  сверх порога текучести и разрыв балки сверх порога прочности.
  Демпфер считается от приведённой массы пары узлов (`d = 2·ζ·√(k·m_red)`),
  поэтому явный интегратор не взрывается.
- `vehicle.py` — кузов из узлов (сечения × 3 уровня: днище, линия окон, крыша)
  + 4 колеса на подвеске: 4 жёстких рычага (держат колесо продольно и
  поперечно) и 2 мягкие пружины к крыше (ход подвески ~2 Гц).
  Жёсткость кузова и подвески масштабируется с массой машины — иначе у лёгкой
  машины собственная частота решётки приближается к пределу устойчивости
  интегратора и кузов «взрывается».
  Ящики-препятствия: трение о грань + жёсткое выталкивание узла наружу,
  если он ушёл внутрь глубже 5 см — застрять в ящике нельзя.
  Жёсткость и порог текучести балок зависят от места: нос и корма — зоны
  смятия (мягче, текут раньше, рвутся быстрее), салон — жёсткая клетка.
  Сквозных балок «через весь кузов» нет намеренно: иначе удар обходит зону
  смятия стороной и машина просто отскакивает от стены.
  Шина: продольное проскальзывание + угол увода, круг сцепления, μ из конфига.
  Мотор — кривая момента из конфига с отсечкой, передачи + задняя, автомат
  или ручная КПП, вязкая блокировка дифференциала, антипробуксовка.
- `garage.py` — загрузка и валидация JSON-конфигов машин (`vehicles/*.json`).
- `modes.py` — режимы: свободная езда, тайм-трайл (чекпоинты на кольце трассы,
  таймер, рекорды в `~/.beamng_lite/records.json`), дрифт-скоринг.
- `terrain.py` — фрактальный value-noise 400×400 м, плоская стартовая зона,
  два трамплина, волны и препятствия: две неподвижные стены для крэш-тестов,
  пирамида из ящиков, слалом из лёгких ящиков (90 кг), бетонные блоки (2.6 т)
  и разбросанные по карте контейнеры. Всё, кроме стен, подвижное, с сухим
  трением о грунт — можно снести и протащить по полю.
  Прямая по курсу от старта оставлена свободной: там трамплины.
  Меш раскрашивается по уклону/высоте; есть дневная и ночная палитра (луна).
- `body.py` — «шкура» кузова: ~500 вершин и треугольников, профиль из конфига
  (вертикальный борт до линии окон, сужение к крыше, кромки бамперов).
  Заливка плоская, по граням: каждое ребро профиля видно, границы стёкол и
  фар резкие — никакого «мыла» от сглаженных нормалей.
  Каждая вершина привязана к четырём ближайшим узлам физики с весами ~1/d²,
  поэтому шкура мнётся вместе с рамой: физика остаётся дешёвой, а картинка —
  плотной. По этой же шкуре построена клетка контактных точек (~130 штук):
  удары считаются по ней, а не по восьми углам кузова, иначе небольшой ящик
  просто проскакивает между узлами и столкновения не происходит.
- `render.py` — фиксированный конвейер OpenGL: ландшафт вершинными массивами
  (одна отрисовка на 73k треугольников), кузов панелями + балки, окрашенные
  по накопленной деформации (зелёный → красный), HUD текстурой.
  Blob-тени от машины и ящиков, дым и обломки — билборды, солнце/звёзды,
  конусы света фар ночью.
- `audio.py` — процедурный звук (сэмплы генерируются в numpy, играет
  pygame.mixer): двигатель — три слоя по оборотам, удары, визг шин, скрежет
  кузова. Без аудиоустройства — тихо.
- `effects.py` — обломки и дым: пулы частиц с гравитацией/затуханием.
- `camera.py` — погоня / орбита / капот / свободная, тряска от ударов.
- `ui.py` — HUD, меню, гараж, экран помощи (pygame-поверхности → текстуры).
- `main.py` — главный цикл: меню, ввод, фиксированный шаг физики 60 Гц,
  интеграция режимов, эффектов и звука.
- Интегратор: полунеявный Эйлер, 12 подшагов на кадр (720 Гц), физика идёт
  фиксированным шагом 1/60 с независимо от FPS.
- Матрицы вида и проекции считаются вручную — библиотека GLU не нужна.
- Ландшафт грузится в VBO, HUD обновляется 10 раз в секунду маленькой
  текстурой: рендер не упирается в Python.

## Тесты

```bash
python -m pytest tests/ -q
```

23 теста: валидация конфигов гаража, устойчивость физики всех машин,
крэш-тест в стену, «не застрять в ящике», респавн, КПП, логика режимов
(тайм-трайл, дрифт), дым/обломки, ночная палитра ландшафта.

## Замеры (headless, ровная поверхность)

| Параметр | Значение |
|---|---|
| 0–100 км/ч (седан) | ~6.9 с |
| Максимальная скорость (седан) | ~182 км/ч |
| Торможение 180→0 | 3.8 с / 94 м (≈1.3 g) |
| Статические нагрузки на колёса | 2848 / 2848 / 2856 / 2856 Н (симметрия) |
| Скорость симуляции | ~4–5× реального времени (только физика) |

| Повреждения за 30 с гонки по холмам на полном газу | 13 % |
| Прыжок с трамплина (полёт ~7 с) | 17 % |
| Падение с 2 м | 0.2 % |

## Крэш-тесты (headless, лоб в неподвижную стену)

| Скорость | Повреждения | Оборвано балок |
|---|---|---|
| 30 км/ч | 14 % | 0 |
| 60 км/ч | 35 % | 0 |
| 90 км/ч | 50 % | 0 |
| 130 км/ч | 69 % | 2 |
| 134 км/ч (полное сминание носа) | 84 % | 12 |

Удар на 84 км/ч по подвижным ящикам: лёгкий ящик 90 кг — 37 % повреждений,
ящик 240 кг — 43 %, контейнер 850 кг — 43 %, бетонный блок 2.6 т — 34 %.
После любого удара внутри ящика не остаётся ни одного узла — проверяется
тестом `test_no_stuck_in_box`: машина всегда оказывается снаружи и может уехать.
Повреждения считаются по самой пострадавшей четверти балок — среднее по всем
показывало бы 2 % на разбитой вдребезги машине.

## Что нового в этой версии

* **Гараж.** Машины — JSON-конфиги (`beamng_lite/vehicles/`): седан, пикап,
  багги и монстр-трак с разными кузовами, приводом, моторами и колёсами.
  Выбор в меню, `python run.py --vehicle pickup`, `--list-vehicles`.
* **Режимы игры.** Свободная езда, тайм-трайл по 12 воротам на кольце трассы
  (таймер в HUD, рекорды в `~/.beamng_lite/records.json`) и дрифт-скоринг
  с комбо. Ворота видны в мире столбами: следующая оранжевая, старт зелёный.
* **Звук.** Процедурный: двигатель (обороты + газ), удары, визг шин,
  скрежет кузова по грунту.
* **Свет и тени.** Blob-тени от машины и ящиков, солнце и звёзды, ночной
  режим с конусами света фар и пятнами на земле.
* **Дым от шин** при пробуксовке и заносе.
* **Тесты и упаковка.** `pytest` (23 теста), `pyproject.toml`,
  консольная команда `beamng-lite` после `pip install .`.
* **Ландшафт переписан.** Value-noise теперь строится по отдельной сетке на
  каждую октаву (раньше пять октав шли по одной сетке 9×9 и давали «косую»
  рябь). Сетка 224×224 (100 352 треугольника), раскраска — трава/грунт/камень
  по уклону и высоте, без шахматки и спекла. По карте проложена грунтовая
  трасса: кольцо радиусом 72 м плюс прямая-разгонная через центр.
* **Детализация кузова.** Лобовое и заднее стёкла, решётка радиатора, фары и
  фонари отдельными материалами, тёмные бампера и пороги, боковые зеркала.
* **Сочные аварии.**
  * Стёкла **выбивает**: грань-стекло с локальным повреждением > 28 %
    становится чёрным проёмом.
  * **Обломки**: пул из 320 частиц (куски кузова, стекло, грязь) с гравитацией
    и отскоком от земли; количество и разлёт зависят от силы удара.
  * **Тряска камеры** — затухающий импульс по величине удара.
  * **Красная вспышка** на весь экран при сильном столкновении и тост
    «Удар! Повреждения N %».
  * **Отрыв колеса**, если порваны 3 из 4 рычагов подвески.
  * Пластика смятия усилена: порог текучести 4.8 % (в носу — 2.3 %), так что
    вмятины видны уже на 30 км/ч.

## Хочется покрутить

Машины — в `beamng_lite/vehicles/*.json` (геометрия кузова `sections`, колёса,
`gears`, `torque`, `tire_mu`). Физика — константы вверху `vehicle.py`
(жёсткости рычагов/подвески, пороги смятия в `build()`). Трасса тайм-трайла —
`RING_R`/`N_CPS` в `modes.py`.
